HOW TO PUBLISH ON GITHUB PAGES
1. Unzip this folder on your phone/computer.
2. Create a new GitHub repository (or use your old website repository).
3. Upload index.html and the entire assets folder, preserving the folder structure.
4. In the repository, open Settings > Pages.
5. Under Build and deployment, select Deploy from a branch, choose main and /(root), then Save.
6. Wait a minute or two; GitHub will show the website URL in Settings > Pages.

The music starts only after the visitor taps the play button, because phones usually block autoplay.
Only share the MP3 publicly if you have permission to use it.
